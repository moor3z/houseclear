# HouseClear Website

Static, no-backend website — 28 pages generated by `build.py`. Deploy the
contents of the **`site/`** folder to Netlify (or any static host).

## What's included
- **Homepage** — hero, trust section, services, areas, how it works, reviews, FAQ, quote form, CTA
- **12 service pages** (`/services/...`) — unique copy, FAQs, Service + FAQ + Breadcrumb schema
- **12 location pages** (`/house-clearance-<place>/`) — unique local copy, neighbourhood lists, local FAQs
- **Hub pages** — `/services/` and `/areas/`
- **Quote page** (`/quote/`) with Netlify-ready form (photo upload, honeypot) + thanks page
- **sitemap.xml**, **robots.txt**, LocalBusiness schema, mobile sticky Call/WhatsApp/Quote bar

## ⚠️ Reviews — legal requirement (DMCC Act 2024)
The three testimonials in `build.py` (`TESTIMONIALS`) are **placeholders for
layout only** and are labelled as such on the page. Publishing fake or
unverified reviews is an offence under the Digital Markets, Competition and
Consumers Act 2024. Replace them with genuine, verifiable customer reviews
before launch, then re-run the build.

## Forms
The quote form uses **Netlify Forms** (`data-netlify="true"`, honeypot field
`company`). Submissions appear in the Netlify dashboard; add an email
notification there. Photos are directed to WhatsApp rather than uploaded
through the form.

**Turnstile:** a commented-out Cloudflare Turnstile block is in the form
markup — add your site key and the Turnstile script tag, and enable it in
Netlify's form settings (Netlify supports Turnstile natively).

If you deploy to GitHub Pages instead of Netlify, the form needs a different
backend (e.g. a Cloudflare Worker like your quoting-tool proxy, or Formspree).

## Deploy (Netlify + GitHub — recommended)
1. Create a **private** GitHub repo and push this folder (`.gitignore` excludes `site/`; `netlify.toml` sets the build).
2. Netlify: Add new site → Import an existing project → pick the repo. Build settings are read from `netlify.toml` automatically (`python3 build.py` → publish `site`).
3. Attach the houseclear.uk domain to THIS site (Domain management) and delete any older drag-and-drop Netlify sites to avoid duplicate copies.
4. From then on: edit source → commit → push → Netlify builds and deploys the full site automatically. Every deploy is a complete snapshot with one-click rollback.

Manual alternative: run `python3 build.py` locally and drag the **entire `site/` folder** into Netlify — never a partial folder, as deploys replace the whole site.

## GEO / LLM optimisation (AI Overviews, ChatGPT, Perplexity, Claude)
Built in:
- **`/llms.txt`** — a plain-markdown map of the business and every page (llmstxt.org standard)
- **AI crawlers allowed** in `robots.txt` — GPTBot, OAI-SearchBot, ClaudeBot, PerplexityBot, Google-Extended, Applebot-Extended, CCBot and more
- **"At a glance" blocks** on every service and location page — self-contained, quotable factual summaries that generative engines can lift verbatim
- **`/about/` entity page** — plain-fact E-E-A-T statements (who, credentials, process, coverage)
- **Entity schema** — LocalBusiness with `knowsAbout`, `slogan` and a `sameAs` array

Off-site actions that matter just as much (LLMs weigh third-party corroboration heavily):
1. **Google Business Profile** — create/verify it, use the exact same name, phone and description as the site, then add its URL to `sameAs` in `build.py`
2. **Citations** — consistent NAP on Yell, Checkatrade, Trustpilot, Facebook etc.; add each profile to `sameAs`
3. **Genuine reviews on third-party platforms** — AI answers lean on Google/Trustpilot reviews when recommending local services
4. **Re-run the build** after adding `sameAs` URLs

## Adding pages later
- **New location:** add an entry to `LOCATIONS` in `locations_data.py` (copy an
  existing one as a template — slug, title, meta, h1, 3 intro paragraphs,
  towns list, 4 FAQs, related locations). Run `python3 build.py`. The page,
  nav links, footer, area grids and sitemap all update automatically.
- **New service:** same, in `services_data.py`.
