# HouseClear website (houseclear.uk)

Static site for HouseClear, a trading name of Tidy Up Ltd. 43 indexable pages
generated by `build.py`; no backend.

## How it deploys
Netlify is linked to this repo. Every push to `main` runs `python3 build.py`
and publishes the generated `site/` folder (see `netlify.toml`). `site/` is
not committed. If a build fails, the previous deploy stays live.

## Files
| File | What it holds |
|---|---|
| `build.py` | Config (phone, GA4 ID, starting price, review count), templates, schema, page builders |
| `services_data.py` | 10 service pages |
| `locations_data.py` | 19 location pages |
| `guides_data.py` | 7 guides (`updated` sets the visible date and `dateModified`) |
| `styles.css`, `site.js` | Styles and behaviour; URLs are cache-busted by content hash |
| `brand/` | Favicons, hero images, og-image |
| `netlify.toml` | Build command, publish folder, security headers |

## Things to keep current (top of `build.py`)
- `GOOGLE_REVIEW_COUNT`: update when the Google review count changes
- `PRICE_FROM` / `PRICE_FROM_NET`: starting price shown sitewide
- `PHONE`: HouseClear's own line (01244 722 330); the Tidy Up 0151 number is not used here
- `GA4_ID`: HouseClear GA4 property

## Tracking
GA4 loads after page load. `site.js` fires `generate_lead` on `/quote/thanks/`
and `phone_click`, `whatsapp_click`, `email_click` on contact links.

## Forms
The quote form uses Netlify Forms (honeypot field `company`). Submissions
appear in the Netlify dashboard under Forms.

## Reviews
`TESTIMONIALS` in `build.py` are genuine Google reviews. Only add real,
verifiable reviews (DMCC Act 2024).
